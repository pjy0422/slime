# Repository agent instructions

## Required first step

At the start of every task in this repository, before planning, reviewing,
editing, testing, or running other repository commands:

1. List the contents of `.claude/skills`.
2. Read every `.claude/skills/*/SKILL.md` file completely.
3. Follow every skill whose scope applies to the task.

Repeat this discovery and reading step for each new task; do not rely on skill
contents remembered from an earlier task. If the directory or a skill file
cannot be read, report that explicitly before continuing with the best safe
fallback.
